Xbox：第一方组织与 IP 重组

核心 IP 向大发行单元集中，工作室同步收缩

核心结论 · KEY CONCLUSION

Xbox 重组的重点不只是减员，而是重新分配核心游戏系列的开发责任。

本周要点
  • 组织调整《光环》下一款作品交由 Activision 专门团队；多家工作室调整归属。[01]
  • 人员收缩官方披露裁减 268 岗；拟关闭、员工磋商与媒体个案分列。[01]

Activision 与 Bethesda 都是 Microsoft 旗下业务。本次所述调整是集团内部重新分工，不是把游戏卖给外部公司。

02Xbox 裁减 268 岗，拟关闭事项另行磋商9/22–23官方公告与媒体个案分列
